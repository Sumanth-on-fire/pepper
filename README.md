# pepper
An 360 app for you to upload old papers and generate new questions from them online

## Use cases.
1. The user is able to upload pdfs into the website, 

2. The user should be able to create a workspace.

3. The user should be able to add the created files into the workspace.

4. The user should be able to ask questions in that workspace using the chat interface inside of the workspace.

### What backend developer should be able to do.
1. he should first be able to sign up. And verify his email.
2. He should be able to signin.
3. He should bt able to use the credential to send the signed in token to create a workspace.
4. He should be able to upload files in that works space.
5. He should be able to chat with the bot based on the references of the uploaded files and the input prompt.
